# indic-orf

**Can oral reading fluency be scored from open Indic ASR output accurately
enough to be useful to a teacher?**

Indian classrooms assess reading fluency by having a teacher listen to each
child, one at a time. It does not scale, and ratings vary between teachers.
This repo tests whether open models can do part of that job.

## Status
Week 1 of 6. Currently: benchmarking `bodhan-ai/indic-transcribe-core` on
children's read speech.

## Data
ASER corpus (Pratham Education Foundation), children aged 6–14 reading in
Hindi, Marathi and English. CC BY-NC-SA 4.0 — non-commercial, share-alike.
Audio is AMR-WB, 16 kHz mono, lossy at source. No audio is committed here.
Cite: Agarwal, Gupchup & Baghel, ICASSP 2020.
